# Azimjon Kamolov

English teacher (Multilevel & IELTS) and master's student in **Information Technologies in Education** at Karshi State Technical University, Uzbekistan. I research **gamification in education**: how points, levels and leaderboards change the way students practise, and how game elements can adapt to each learner.

Before teaching I studied computer science at Sejong University in Seoul (2016–2020) and worked as a web developer.

- **CodeArena**: online judge for university programming courses (master's dissertation, in development)
